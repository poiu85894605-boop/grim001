# 🔖 2026 디지털 책갈피 - 그림책으로 키우는 문해력

EBS '임금님 귀는 당나귀 귀' 그림책을 활용하여 학생들의 **문해력 향상**과 **자기존중(자존감) 형성**을 돕는 웹 기반 디지털 배움 노트입니다. 단계별 활동을 통해 칭찬 도장을 모으고 최종 수료증을 발급받을 수 있습니다.

## ✨ 주요 기능 및 4단계 학습 과정
1. **🧩 1단계: 스토리 이해** - 이야기의 흐름에 맞게 1번부터 6번까지 순서 나열하기
2. **📚 2단계: 기초 어휘** - 낱말 뜻 매칭 및 보기를 활용한 문장 완성 퀴즈
3. **❓ 3단계: 스토리 퀴즈** - 중심 내용을 점검하는 3지선다 및 O/X 퀴즈 5문항
4. **🌱 4단계: 배움 노트 & 수료증** - [자기존중] 가치를 배우고 나만의 다짐 카드 작성 후 디지털 수료증 인쇄/복사

## 🚀 사용 방법
1. 저장소 우측 상단의 **Code** 버튼을 누르고 **Download ZIP**을 클릭하여 압축 파일로 다운로드합니다.
2. 압축을 푼 뒤, `index.html` 파일을 더블 클릭하면 브라우저에서 바로 실행됩니다.
3. 학습자 정보를 입력한 뒤 1단계부터 차례대로 학습을 진행하세요.

## 💡 개발 스펙
- HTML5 / CSS3 / JavaScript (Vanilla JS)
- 별도의 서버 설치 없이 웹 브라우저 환경에서 단독 실행 가능
